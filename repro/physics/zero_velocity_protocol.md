# 무입력 초기속도와 이력 개입 프로토콜

C 이후 동결 모델의 0.25초 무입력 반응을 진단한다. 재학습·probe 적합·physics loss·sealed test·다단계 D는 하지 않는다. C의 완료 SHA와 원 무입력 결과를 재사용한다. 새 결과 폴더에서만 실행한다.

## 조건과 물리적 일관성

C의 동일 후보40episodes와 분할을 사용한다. 각 episode의 raw10,15,…70 중 전체23조건의 경로가 안전한 첫 위치를 선택한다. 선택한 위치 q를 고정하고 v=0 및 ±x/±y의 크기0.1/0.25/0.5를 비교한다(13개). 지난0.5초와 미래0.25초 동안 raw control=0인 물리적으로 일관된 과거 상태·영상 context를 새로 생성한다. 검증된 implicit Euler 식을 역으로 풀어 과거 초기상태를 얻고, 실제 MuJoCo로 순방향 재생한다. 이미지 시점은 proprio보다0.01초 과거인 기존 저장 규칙을 유지한다. raw step마다 clip을 적용하고 모든 substep trace를 보존한다. 과거 영상을 고정한 채 속도 채널만 고치는 입력은 사용하지 않는다.

이력 대조: 같은 현재 q/v(0, ±0.25x, ±0.25y)에 도달하되 지난0.5초의 control을(+0.05,0) 또는(−0.05,0)으로 바꾼다(추가10개). 미래는 모두0이다. 현재 상태가 같고 이력만 다른 조건의 예측 차이를 평가한다. 영상·proprio·과거 action을 모두 실제 생성된 이력에 맞춘다. 첫 이미지 시점−0.01초까지 같은 과거 control로 연장한다.

23개 조건 전체의 과거0.51초+미래0.25초 경로가 margin>0.004, 무clip인 위치만 주 분석에 선택한다. 모델 출력은 선택에 사용하지 않는다. 부족한 표본을 다른 episode로 대체하거나 기준을 완화하지 않는다. C의 후보 fit/tune/development를 분리한다. episode가 아닌 새 위치를 독립표본처럼 추가하지 않는다. 합성 context는 WM train 영역의 위치를 쓰지만 원 데이터 시간 패턴과 다르므로 unseen 일반화로 부르지 않는다.

## 오차 분리

coast 이력의 모델 속도 출력을 f(v)라 하고 b=f(0), 각 반경의 중앙차분 J_r[:,j]=(f(+r e_j)−f(−r e_j))/(2r)를 구한다. 환경은 b=0, J=αI, α=Ah^25다. 각 축 조건에서 정확한 벡터 분해는 오차=b+(J_r−αI)v+비선형짝수잔차다. 주 계수는 사전 고정 r=0.25이며 다른 r는 크기 민감도다. 이 계수는 물리 파라미터나 모델 재학습 결과가 아니라 유한차분 요약이다.

속도·위치 L2, 축별 signed bias, b norm, J 대각/비대각, 위 세 항 norm과 벡터 closure, b를 뺀 진단 오차, 부호반전/출력고정/속도유지 대조, K 증가 빈도(수치구분1e-8), 동일 q/v에서 ±과거힘 이력효과를 저장한다. 항들의 norm은 더해서 총오차가 되지 않으므로 가산 기여율을 주장하지 않는다. 원 C 무입력 결과는 참고로 재사용하되 합성 context와 표본 차이 때문에 직접 성능 향상으로 부르지 않는다.

episode 내 평균→episode 동일가중, bootstrap10000 seed0 탐색적95% CI. 분기들을 독립표본으로 세지 않는다. 표본 부족 시 확정적 결론을 피한다.

## 검증과 실행 상한

환경식↔새 trace 최대차이1e-10, 현재 상태 도달1e-10, clip/접촉0, 에너지 수지 잔차1e-10. 렌더링은 별도 sim에서 수행하여 dynamics trace에 영향을 주지 않는다. 최초 calibration 두 원영상과 원이미지시점 상태 재렌더를 비교하고 mean absolute RGB 차이≤3/255를 요구한다. 실패하면 기준을 완화하지 않고 원인을 진단한다. 원 C full context로 최대2개 zero baseline 재추론 차이≤1e-4, 과거/현재 proprio 역변환 roundtrip≤1e-6, 정규화/출력 유한성, 가중치·입력 SHA 불변을 확인한다.
